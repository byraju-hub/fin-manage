# 재정 관리(fin-manage) 한눈에 보는 구조

> 2026-11-17 기준, v0.2.0 (DB 구조 번호 4, 마이그레이션 001~004). 더 자세한 기술 설명은 `ARCHITECTURE.md`, 쓰는 방법은 `manual.md`.

## 1. 한 장 그림

```
 [교적 관리 cm_]  ── 같은 DB·같은 로그인 ──  [재정 관리 fm_]  ── (부서 관리 dm_: 아직 연결 안 함)
   교인·세대·조직          ▲                    돈의 흐름 전부
                           │ '재정 열기' 입장권(30초·1회용)
 브라우저(폰/PC) ─ SvelteKit 화면(정적 파일) ─ PHP API(/api/v1) ─ MariaDB(fm_ 표)
```

| 층 | 무엇으로 | 하는 일 |
|---|---|---|
| 화면 | SvelteKit(정적, 폰 우선) | 메뉴·입력·보고서·인쇄 |
| API | 프레임워크 없는 PHP 8 | 권한 확인, 결재 규칙, 마감, 금액 계산 (**모든 규칙은 여기서**) |
| 자료 | MariaDB `fm_*` | 금액은 원(정수). 지우지 않고 취소로 남김 |
| 교적 연결 | `cm_*`를 읽기만 | 로그인·교인 이름·조직 불러오기 |
| 설치 | `/install/` 마법사 | 설치·업데이트(DB 변경은 번호 붙은 마이그레이션 001~004) |

## 2. 누가 무엇을 하나 (권한)

교적 계정으로 로그인 → **재정 사용 신청 → 관리자 승인 → 역할 지정**.

| 역할 | 하는 일 |
|---|---|
| 재정 관리자 | 설정·승인·백업·결재 규칙 (교적 최고관리자 아님, 재정에서 따로 지정) |
| 재정 담당 | 헌금 입력·장부·예산·영수증·지급 처리 |
| 계수 위원 | 헌금 묶음 계수(입장 중인 묶음만, 마감 뒤엔 못 봄) |
| 재정위원장 · 담임목사 | 결재선에 들어가는 역할(기안자 본인은 제외) |
| 감사 · 열람 | 보기만 (개인별 헌금은 `can_view_donors` 지정자만) |
| 부서 회계·부서장 | 자기 부서 예산·결의서만 |
| **체험 계정** | `/fm/demo` 를 열면 자동 로그인 → 가짜 자료만 보기 전용 |

중요한 일(승인·마감·영수증 발급 등)은 **10분 이내 비밀번호 재확인**.

```

헌금 ▾          헌금 입력(묶음·빠른 입력·계수 대조·마감) · 기부금 영수증
지출 ▾          지출결의서 · 결재함
장부 ▾          장부(수입·지출·이체·잔액) · 예산 · 마감(월/연)
보고서          주간 보고 · 주보 명단 · 월 보고 · 집행 현황 · 결산서
```

## 4. 돈이 흐르는 길 (핵심 업무 흐름)

```
 수입 ┌ 주일/수요 등 헌금 묶음 ─ 이름·금액 빠른 입력 ─ 계수 위원 대조 ─ 마감 ─┐
      └ 통장 내역 붙여넣기(계좌이체) ─────────────────────────────────────────┤
                                                                              ▼
 지출  결의서 작성 → 상신(결재선·금액 구간 고정) → 결재(사후 확인·대리) → 지급 처리 ─→ 【장부】
       직접 지출(소액, 증빙 사진/사유) ──────────────────────────────────────────┘     │
 예산  편성 → 확정 → 추경·전용 ── 지출 때 초과 경고/차단 ────────────────────────────┤
                                                                                     ▼
 정리  월 마감 → 연 마감·이월 → 결산서 / 연말 기부금 영수증(가족 합산, 발급 대장, 정정)
```

- 마감한 달은 고칠 수 없고, 취소는 반대 기록으로 남깁니다.
- 결재선은 상신 때 **고정**되고 내용 해시로 변조를 막습니다.

## 6. 안전장치

- 로그인: 교적 해시를 읽어 검증, 재정 전용 세션(`fm_sid`), CSRF·Origin 검사, 시도 제한
- 주민번호: 암호화 보관 또는 보관 안 함(설정), 기간 지난 번호 정리
- 개인별 헌금 열람은 모두 `access_log`에 기록
- 백업: 내려받기·되살리기(승인·역할·설정은 덮어쓰지 않음), 호스팅 요청 128KB 제한은 조각 업로드로 해결
- 개인정보 처리방침(`/privacy`): 책임자·연락처는 교적 `church_info`(`privacyOfficer/Phone/Email`)를 읽기만 함. 접속·변경 기록은 2년 이상, 권한 변경 기록은 3년 이상 보관(지우는 기능 없음), 주민번호 정리는 최소 5년
- 체험 모드: 보기 외 요청 403, 설정·백업·내려받기 화면 차단, 진짜 자료는 읽지 않음

## 8. 첨부 PDF 검토: 디모데 웹교적관리 6.0 '웹재정관리' 매뉴얼

첨부 두 파일은 같은 시판 프로그램의 재정 부분(수입·지출 항목 설정, 수입 기록, 가족 단위 검색·기부금 증명서, 작정 헌금) 설명서입니다. 우리 구조와 견줘 보았습니다.

### 이미 같거나 더 나은 것
| 디모데 | fin-manage |
|---|---|
| 수입·지출 항목을 6자리 코드로 수동 관리, 연도마다 설정·"코드 자동부여는 연도 시작 전에만, 아니면 꼬임" 경고 | 수입 항목은 이름 트리(3단계)로 연도와 무관하게 유지, 코드 꼬임 문제가 없음 |
| 전년도 항목 불러오기 / 백업 항목 불러오기 | 항목이 연도에 묶이지 않아 불필요. 백업·되살리기는 전체 단위로 있음 |
| 수입기록(날짜·항목·이름·금액·비고·저장·수정·삭제) | 헌금 묶음 빠른 입력 + 계수 대조 + 마감 (한 사람이 아닌 두 사람 확인) |
| 하위 항목이 있으면 하위로만 기록 | 같은 규칙(상위 항목은 선택 불가) |
| 가족 단위 검색 → 기부금납입증명서 인쇄, 배우자/가족 포함 | 가족 합산(대표 지정), 발급 대장, 정정·재발급, CSV |
| 교회 계좌 선택 | 계좌(wallets)·회계(funds)별 장부와 잔액 |

### 추가를 검토할 만한 것 (제안, 우선순위 순)
1. **작정헌금(약정) 기록과 이행률** — 디모데 2-4 전체가 이 기능. 작정 금액·낸 금액·잔액·% 를 사람별·항목별로 봄. 우리에겐 없음. 건축헌금·선교헌금을 쓰는 교회에 유용. 표 2개(작정, 작정-헌금 연결)와 화면 1개 정도.
2. **금액 단축 입력** — 숫자 + `R`=+100, `T`=+1000, `Y`=+10000, 천 단위 자동 입력. 현장 입력 속도에 직결. 우리 빠른 입력에 천 단위 자동 입력 옵션이 있는지 점검하고, 없으면 추가.
3. **입력 편의** — "비고 입력값 유지", "금액 입력값 유지", 입력 결과 실시간 목록, **'헌금 항목별 합계 보기'** 버튼(그날 항목별 합). 우리 묶음 화면에 항목별 합계가 보이는지 확인 후 보강.
4. **예배 회차 표시(몇째 주 몇 부 예배)** — 우리는 날짜+구분(주일/수요…)만 있음. 1부·2부 예배를 나누는 교회라면 묶음에 '부' 칸이 필요(선택 항목으로).
5. **영수증 인쇄 형식 '합계/월별'과 기간 지정, 월·분기 단위 조회** — 우리는 과세 연도 단위. 기간(월·분기) 지정 조회와 월별 인쇄 형식 추가 검토. 납세번호·발행번호는 이미 교회 정보·문서번호로 있음.
6. **세대주 맞춤 도구** — 교적에서 세대주가 바뀌면 합산 대상을 맞춰 주는 버튼. 우리는 '합산 제안'만 있고 변경 반영 버튼은 없음 → 교적 세대 변경 감지 후 제안 표시 정도로.
7. **헌금자 순위 · 입금전표 · 헌금자 명단** — 디모데 메뉴에 있음(화면 내용은 첨부에 없음). 순위는 **개인 헌금 노출 위험**이 있어 권한·열람 기록과 함께 신중히, 입금전표(은행 입금 증빙 인쇄)는 월 보고서의 변형으로 가능.
8. **교구(소그룹) 단위 조회** — 작정·헌금 검색의 조건. 교적 조직 구조가 있으니 재정 단위와 별개로 '교구별 헌금 합계' 보고서는 가능.

### 일부러 하지 않는 것
- 코드를 사람이 직접 부여하는 방식(연도 꼬임의 원인).
- 수입 기록을 줄마다 즉시 확정하는 방식 — 우리는 계수 대조·마감 전엔 장부에 안 올라가서 오입력이 장부를 오염시키지 않음.
- 주민번호를 검색창에 직접 입력해 조회 — 우리는 암호화 보관/미보관 설정과 열람 기록으로 다룸.

### 확인할 것
첨부 PDF는 화면 설명뿐이라 **계산 규칙(작정 잔액·% 산식 등)은 알 수 없습니다.** 작정헌금을 넣는다면 교회에서 실제로 쓰는 방식(연 단위인지, 분할 납부인지)을 먼저 정해야 합니다.
