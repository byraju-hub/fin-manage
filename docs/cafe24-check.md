# 카페24 실사용 점검표

로컬 시험은 자동으로 돌지만, 카페24(공유 호스팅)에서 **로그인한 상태로** 쓰는 것은 사람이 한 번 확인해야 합니다. 샘플 교회(`https://byraju.mycafe24.com/fm/`)에서 아래를 차례로 해 보세요. 이상하면 그 줄 번호와 화면을 알려 주세요.

## 0. 올린 뒤 준비
- [ ] 새 파일을 올렸다면 `…/fm/install/` 을 한 번 열었다 ("이미 설치됨"이 보이면 정상 — 데이터베이스 변경과 마무리는 이때 적용됩니다)
- [ ] 첫 화면이 열리고 상단 메뉴가 `대시보드 · 헌금 · 지출 · 장부 · 보고서 · 설정` 으로 보인다

## 1. 로그인·권한
- [ ] 교적 아이디·비밀번호로 로그인된다. 틀린 비밀번호는 거절된다
- [ ] (관리자) 설정 › 재정 사용 승인에서 신청 승인·역할 지정이 된다 (비밀번호 재확인 창이 뜬다)
- [ ] 휴대폰에서 상단 메뉴(☰)가 펼쳐지고 묶음별로 보인다

## 2. 샘플로 한 바퀴 (설정 › 백업 › 샘플 자료 올리기)
- [ ] 샘플이 올라가고 대시보드에 수입·지출·잔액·8주 헌금 그래프가 나온다
- [ ] 헌금 화면: 묶음을 열어 이름(초성)·금액 입력, Enter 로 다음 줄, 마감하면 장부에 올라간다
- [ ] 예산 화면: 부서별 집행률이 보인다. (부서 회계 계정으로 로그인하면 자기 부서만 보인다)
- [ ] 지출결의서: 새로 쓰고, **휴대폰으로 영수증 사진을 올린다**(요청 크기 제한 점검) → 상신 → 결재선 이름이 나온다
- [ ] 결재함에서 결재(비밀번호 재확인), 지급 처리 후 장부에 지출이 생긴다
- [ ] 영수증: 작년 과세 연도로 미리보기 → 발급 → 인쇄(PDF) 미리보기에 교회 이름·고유번호가 나온다
- [ ] 설정 › 백업: 백업 내려받기가 된다
- [ ] 설정 › 백업 › 샘플 지우기 (직접 입력한 자료가 있으면 한 번 더 묻는다)

## 3. 호스팅 한계 점검
- [ ] 큰 사진(5MB 이상)을 결의서 증빙으로 올려도 줄어서 올라간다
- [ ] 백업 되살리기(조각 업로드)가 끝난다 — 샘플 올린 상태에서 내려받은 백업으로 시험하고, **승인·역할은 그대로 남는지** 확인
- [ ] 엑셀 가져오기: 헌금 내역 CSV(수백 줄)가 오류 없이 검사·가져오기 된다

## 4. 보안 확인 (로그인 없이 주소창에서)
- [ ] `…/fm/data/config.php` → 403 (또는 404)
- [ ] `…/fm/migrations/001_init.php` → 403
- [ ] `…/fm/api/v1/admin/access` → 로그인 필요 오류(401)
- [ ] `http://` 로 열면 `https://` 로 바뀐다

## 5. 실제 운영 전에
- [ ] 설정 › 교회 정보·영수증·보안에서 **고유번호·소재지·대표자**를 채우고 직인을 올렸다
- [ ] 주민번호 방식(보관/미보관)을 정했다. 보관이면 **암호화 열쇠를 안전한 곳에 따로 적어 두었다**
- [ ] 샘플을 지웠다
- [ ] 영수증 서식과 구분 코드를 세무 담당자와 확인했다
- [ ] 백업 파일과 서버 `data/vouchers`·`data/proofs`(증빙 사진) 폴더를 정기적으로 내려받는 방법을 정했다

## 6. 교적과 연결 (ch-manage 를 구조 번호 7 로 올린 뒤)
- [ ] 교적에서 '재정 열기' → 비밀번호 없이 재정 첫 화면이 열리고, 주소창에 `?t=` 값이 남지 않는다
- [ ] 같은 주소를 뒤로가기/다시 열기 하면 입장권 안내와 함께 로그인 창이 나온다
- [ ] 재정 상단 '바로가기 ▾ › 교적 관리'로 교적이 열린다 (폴더 이름이 다르면 설정에서 바꿈)
- [ ] 재정 사용을 신청하지 않은 교적 계정으로 '재정 열기' → '재정 사용 신청' 화면
